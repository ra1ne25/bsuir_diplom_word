# Генерация DOCX по шаблону

## Установка

```bash
python -m venv .venv
. .venv/Scripts/activate  # Windows PowerShell: .venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

## Шаблон
Положите файл `templates/template.docx` с маркерами в фигурных скобках:
- `{ФИОБел}`
- `{ФИОРусс}`
- `{годМакет}`
- `{паспортНомер}` и/или `{паспортНомер1}`…`{паспортНомер14}`
- `{картинка1}`, `{картинка2}` — будут заменены загруженными изображениями.

Для макета номера используйте только позиционные клетки: ① ② ③ ④ ⑤ ⑥ ⑦ ⑧ ⑨ ⑩ ⑪ ⑫ ⑬ ⑭ — каждая клетка в отдельном run.

Изображения масштабируются с сохранением пропорций под A4 (горизонтальная ориентация) и не выходят за безопасную область листа.

## Запуск

```bash
python app.py
```

Откройте `http://localhost:5000` и заполните форму.
